# Método ÓRBITA

> Desenvolvimento de Software Assistido por IA com Governança Humana.

Este repositório documenta o **Método ÓRBITA**, um modelo particular de organização do desenvolvimento de software idealizado e utilizado por **João Corsino**, em formação para atuar como Analista de Sistemas.

A documentação completa do método será desenvolvida e homologada de forma incremental neste próprio repositório.

## Princípio central

**Planejar → Executar → Evidenciar → Homologar**

O método separa claramente os papéis do responsável humano pelo projeto, do agente de planejamento, do agente de implementação e do GitHub como fonte canônica do estado aprovado do projeto.
