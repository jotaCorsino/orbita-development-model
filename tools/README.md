# ÓRBITA Tools — catálogo independente

**Estado:** estrutura, critérios e contrato de consumo homologados e integrados ao método pela ORB-EVO-001. Consulte a [regra vigente](../docs/10-IDENTIDADE-E-AMBIENTE-DO-PROJETO.md). **Ferramentas admitidas: nenhuma.** A biblioteca fornece critérios e um [modelo de ficha](modelo-de-ficha.md), não acesso a ferramentas particulares. Cada projeto seleciona ferramentas conforme necessidades, direitos, segurança e autorização, sem herança automática.

[Contrato de admissão e consumo](../proposals/007-09B-ORBITA-TOOLS.md). O [exemplo fictício de avaliação](revisao-de-interfaces.md) demonstra como avaliar uma categoria de ferramenta; não indica produto existente, distribuição ou instalação. Fontes profissionais públicas ou ferramentas de terceiros poderão ser avaliadas independentemente quando houver necessidade. Nenhum código, configuração, identidade ou referência de consumidor pertence ao catálogo. Aplicar ISO-001.
